# Artifacts

This directory stores representative outputs generated by the paper-aligned
experiment.

## Layout

- `schedules/`: representative schedule JSON files.
- `traces/`: per-robot execution traces and resource mutex traces.
- `logs/`: Z3 result files and violation logs.
- `figures/`: architecture and paper figures.

The files are generated by:

```bash
python -m synasc2026.experiments.run_veriros_paper_experiment
```
